        Connect an AI client

        MCP endpoint: with header Authorization: Bearer <token>. Download a ready-made config (your NAS address and token are already filled in):

        ⬇ Antigravity (mcp_config.json) ⬇ Claude Code (.mcp.json) ⬇ Codex (config.toml) ⬇ Tool list with schemas (JSON)
        • Antigravity: Agent panel → … → MCP Servers → Manage MCP Servers → View raw config, and paste the file's contents (or save it as ~/.gemini/antigravity/mcp_config.json). Already have other servers? Copy only the "midimcp" entry into your "mcpServers". Then refresh the server list.
        • Claude Code: run the copied command once, or put .mcp.json in a project folder.
        • Codex: add the file's lines to ~/.codex/config.toml and set MIDIMCP_TOKEN as its first comment shows.
        • These files contain your access token: don't share them. More: Setup → Connect AI clients.
